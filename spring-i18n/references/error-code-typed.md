# Typed Error Code (Record-Based)

Type-safe error codes using Java 17 Records. Each code carries its own typed `msg()` and `ex()` methods — parameter count and types are enforced at compile time. No `argCount` declaration needed.

## Core Records

```java
/**
 * 0-argument error code.
 */
public record Err0(String code, String defaultMessage, String[] argNames) implements ErrorCode {

    public Err0(String code, String defaultMessage) {
        this(code, defaultMessage, new String[0]);
    }

    @Override public String code()           { return code; }
    @Override public String defaultMessage() { return defaultMessage; }
    @Override public String[] argNames()     { return argNames; }

    /** Resolve message with current locale. */
    public String msg() {
        return I18nUtil.getOrDefault(code, defaultMessage);
    }

    /** Create exception ready to throw. */
    public BusinessException ex() {
        return new BusinessException(this);
    }
}

/**
 * 1-argument error code. Type parameter T constrains the argument type.
 */
public record Err1<T>(String code, String defaultMessage, String[] argNames) implements ErrorCode {

    public Err1(String code, String defaultMessage) {
        this(code, defaultMessage, new String[0]);
    }

    @Override public String code()           { return code; }
    @Override public String defaultMessage() { return defaultMessage; }
    @Override public String[] argNames()     { return argNames; }

    public String msg(T arg0) {
        return I18nUtil.getOrDefault(code, defaultMessage, arg0);
    }

    public BusinessException ex(T arg0) {
        return new BusinessException(this, arg0);
    }
}

/**
 * 2-argument error code.
 */
public record Err2<T, U>(String code, String defaultMessage, String[] argNames) implements ErrorCode {

    public Err2(String code, String defaultMessage) {
        this(code, defaultMessage, new String[0]);
    }

    @Override public String code()           { return code; }
    @Override public String defaultMessage() { return defaultMessage; }
    @Override public String[] argNames()     { return argNames; }

    public String msg(T arg0, U arg1) {
        return I18nUtil.getOrDefault(code, defaultMessage, arg0, arg1);
    }

    public BusinessException ex(T arg0, U arg1) {
        return new BusinessException(this, arg0, arg1);
    }
}

/**
 * 3-argument error code.
 */
public record Err3<T, U, V>(String code, String defaultMessage, String[] argNames) implements ErrorCode {

    public Err3(String code, String defaultMessage) {
        this(code, defaultMessage, new String[0]);
    }

    @Override public String code()           { return code; }
    @Override public String defaultMessage() { return defaultMessage; }
    @Override public String[] argNames()     { return argNames; }

    public String msg(T arg0, U arg1, V arg2) {
        return I18nUtil.getOrDefault(code, defaultMessage, arg0, arg1, arg2);
    }

    public BusinessException ex(T arg0, U arg1, V arg2) {
        return new BusinessException(this, arg0, arg1, arg2);
    }
}
```

## Module Constants

Each module defines a `final class` with `public static` constants. AI generates these from a template.

```java
/**
 * User module error codes.
 * Generated by AI — do not edit manually.
 */
public final class UserErrors {

    private UserErrors() {} // prevent instantiation

    // 0 args
    public static final Err0 EMAIL_EXISTS = new Err0(
        "user.register.emailExists",
        "Email already registered"
    );

    public static final Err0 LOGIN_INVALID = new Err0(
        "user.login.invalid",
        "Invalid username or password"
    );

    public static final Err0 PASSWORD_MISMATCH = new Err0(
        "user.password.mismatch",
        "Passwords do not match"
    );

    public static final Err0 NOT_FOUND = new Err0(
        "user.notFound",
        "User not found"
    );

    // 1 arg: Integer, with named key
    public static final Err1<Integer> PASSWORD_TOO_SHORT = new Err1<>(
        "user.password.tooShort",
        "Password must be at least {0} characters",
        new String[]{"minLength"}  // ErrorResponse.data: {"minLength": 8}
    );

    public static final Err1<Integer> NAME_TOO_LONG = new Err1<>(
        "user.name.tooLong",
        "Name exceeds {0} characters"
    );

    // 1 arg: String
    public static final Err1<String> STATUS_INVALID = new Err1<>(
        "user.status.invalid",
        "Invalid user status: {0}"
    );

    // 2 args: String, String, with named keys
    public static final Err2<String, String> UPDATE_FAILED = new Err2<>(
        "user.update.failed",
        "Failed to update {0}: {1}",
        new String[]{"field", "reason"}  // ErrorResponse.data: {"field": "...", "reason": "..."}
    );

    public static final Err2<String, String> BIND_ERROR = new Err2<>(
        "user.bind.error",
        "Cannot bind {0} to {1}"
    );

    // 3 args: mixed types
    public static final Err3<String, Integer, Integer> FIELD_RANGE_INVALID = new Err3<>(
        "user.field.rangeInvalid",
        "Field {0} must be between {1} and {2}"
    );
}
```

## Usage

```java
// 0 args — no parameters allowed
throw UserErrors.EMAIL_EXISTS.ex();
String msg = UserErrors.EMAIL_EXISTS.msg();

// 1 arg, Integer — compile error if wrong type
throw UserErrors.PASSWORD_TOO_SHORT.ex(8);
String hint = UserErrors.PASSWORD_TOO_SHORT.msg(8);

// Compile error: expects Integer, got String
// UserErrors.PASSWORD_TOO_SHORT.msg("eight");

// Compile error: expects 1 arg, got 2
// UserErrors.PASSWORD_TOO_SHORT.msg(8, "extra");

// 1 arg, String
throw UserErrors.STATUS_INVALID.ex(status);

// 2 args, String + String
throw UserErrors.UPDATE_FAILED.ex("email", "already in use");

// 2 args, BigDecimal + BigDecimal
throw OrderErrors.AMOUNT_MISMATCH.ex(expectedAmount, actualAmount);

// 3 args, String + Integer + Integer
throw UserErrors.FIELD_RANGE_INVALID.ex("age", 18, 120);

// Direct message without exception
return ApiResult.fail(UserErrors.LOGIN_INVALID.msg());
```

## BusinessException (Record-Aware)

```java
@Getter
public class BusinessException extends RuntimeException {

    private final ErrorCode errorCode;
    private final transient Object[] args;

    // Package-private: use Err*.ex() factories instead
    BusinessException(ErrorCode errorCode, Object... args) {
        super(errorCode.code());
        this.errorCode = errorCode;
        this.args = args;
    }

    public String getLocalizedMessage() {
        return I18nUtil.get(errorCode, args);
    }

    @Override
    public String toString() {
        return errorCode.code() + ": " + getLocalizedMessage();
    }
}
```

No public constructors — all creation goes through `Err*.ex()` which is type-safe.

## API Response

```java
public record ErrorResponse(String code, String message) {
    public static ErrorResponse of(BusinessException e) {
        return new ErrorResponse(e.getErrorCode().code(), e.getLocalizedMessage());
    }
}

@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(BusinessException.class)
    public ResponseEntity<ErrorResponse> handle(BusinessException e) {
        return ResponseEntity
            .status(HttpStatus.BAD_REQUEST)
            .body(ErrorResponse.of(e));
    }
}
```

## AI Generation Prompt

When generating a new module's error codes, AI follows this pattern:

```
Given error definitions:
- user.register.emailExists / "Email already registered" / 0 args
- user.password.tooShort / "Password must be at least {0} characters" / 1 arg: int
- user.update.failed / "Failed to update {0}: {1}" / 2 args: String, String

Generate:
1. Class name: {Module}Errors (e.g., UserErrors)
2. Pick record: Err0, Err1<T>, Err2<T,U>, Err3<T,U,V>
3. Infer T/U/V from placeholder context
4. Generate public static final constants
```

## Comparison: Enum vs Record

| Aspect | Enum (ErrorCode) | Record (Err*) |
|--------|-----------------|---------------|
| **Type safety** | argCount int, runtime check | Generic `<T>`, compile time |
| **Parameter types** | Not constrained | `Err1<Integer>` vs `Err1<String>` |
| **values() / switch** | Yes | No (use constants directly) |
| **AI generation** | Template with argCount | Template with generic type |
| **Readable call site** | `UserErrorCode.PASSWORD_TOO_SHORT` | `UserErrors.PASSWORD_TOO_SHORT` |
| **Module scoping** | `enum UserErrorCode` | `class UserErrors` |

**Recommendation:** Use Record (Err*) for new projects — true compile-time type safety. Use Enum only if you need `values()` iteration or `switch` expressions over all error codes.

## Migration from Enum to Record

Existing enum code:
```java
// Old
throw new BusinessException(UserErrorCode.PASSWORD_TOO_SHORT, 8);
```

New record code:
```java
// New — type-safe, no 'new BusinessException'
throw UserErrors.PASSWORD_TOO_SHORT.ex(8);
```

Both implement `ErrorCode` interface — `GlobalExceptionHandler` handles both without change.
